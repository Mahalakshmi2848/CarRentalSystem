# Car Rental System

A console-based Car Rental System developed using Java and Eclipse IDE.

## Project Overview

This project is designed to manage car rental operations through a simple and user-friendly console interface. It allows users to manage cars, rent and return vehicles, and search for available cars.

## Features

- Add new cars
- View all cars
- Rent a car
- Return a car
- Search cars by ID
- Check car availability
- Customer details management

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE
- Java Collections
- Scanner for user input

## Project Structure

- `Car.java` – Stores car details and availability status
- `Customer.java` – Stores customer information
- `CarRental.java` – Contains the main application and rental operations

## How to Run

1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Make sure Java is installed and configured.
4. Run `CarRental.java` as a Java Application.
5. Use the console menu to perform rental operations.

## Functionalities

The application provides the following menu:

1. Add Car
2. View Cars
3. Rent Car
4. Return Car
5. Search Car
6. Exit
